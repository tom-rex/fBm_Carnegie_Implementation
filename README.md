## Repository Index

| File | Description |
|---|---|
| `Cholesky_Simulation.ipynb` | Simulates fractional Brownian motion (fBm) using the Cholesky decomposition method. |
| `Davies-Harte.ipynb` | Simulates fBm using the Davies-Harte method. |
| `DMA_identification.ipynb` | **(Unfinished)** Implementation of the DMA (Detrended Moving Average) paper, performing a hypothesis test for whether a given path is fBm. |
| `fBm_OU.py` | Contains the helper functions used by `OU_sim.ipynb` and `OU_sim_large_H.ipynb`. |
| `OU_sim.ipynb` | Simulates fBm as a superposition of OU processes, for $H < 1/2$. |
| `OU_sim_large_H.ipynb` | Simulates fBm as a superposition of OU processes, for $H > 1/2$. |
